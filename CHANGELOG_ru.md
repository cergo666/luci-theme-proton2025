## [1.4.4.6]

## Изменения в версии 1.4.4.6

## Новые возможности

- **Эффект Glassmorphism (Frosted Glass)**
  - Стиль матового стекла для карточек, секций CBI, модальных окон, выпадающих списков, всплывающего поиска и подменю навигации
  - Привязан к существующей настройке «Прозрачность» (`proton2025.settings.transparency`): при отключении карточки остаются полностью непрозрачными с нулевой нагрузкой на процессор роутера
  - Устранено наложение повторных размытий: вложенные секции и секции внутри модальных окон автоматически сглаживаются (`backdrop-filter: none`), предотвращая артефакты рендеринга и нагрузку на GPU
  - Исправлен контекст наложения CSS для выпадающих списков (`.cbi-section:has(.cbi-dropdown[open])`), благодаря чему открытое меню больше не перекрывается соседними карточками
  - Элементы выпадающих списков получили полупрозрачную подсветку при наведении на фоне матового стекла

## Сборка

- Версия ресурсов (`__pv`) и пакета поднята до 1.4.4.6

## [1.4.4.5]

## Изменения в версии 1.4.4.5

## Новые возможности
- **Поиск с клавиатуры: Ctrl/⌘+K или /**
  - Ctrl+K / ⌘K откуда угодно и `/` вне текстовых полей переводят фокус в поиск в шапке; пока открыт диалог LuCI, клавиши не перехватываются

- **Быстрое переключение режима темы в шапке**
  - Кнопка рядом с поиском переключает по кругу Авто → Светлая → Тёмная; иконка и подсказка показывают текущий режим, выбор сохраняется на роутере так же, как настройка в панели темы

- **LuCI на главный экран**
  - Манифест веб-приложения, PNG-иконки (в том числе maskable для Android) и apple-touch-icon; LuCI открывается отдельным окном, на iOS заголовком служит имя роутера. Кнопку «Установить» браузеры показывают только по HTTPS; по HTTP работает ярлык на главном экране
## Исправления

- **В 1.4.4 не работала загрузка пакетов на System → Software** (регрессия PR #89)
  - Коммит «Prepare 1.4.4» удалил из `header.ut` тег `<script>` для `js/package-upload.js`, поэтому загрузка нескольких файлов и установка неподписанных `.apk` не запускались, хотя RPC-модуль, ACL и сам скрипт были в пакете
  - Тег возвращён

- **Обновлённые сторонние приложения LuCI оставались в кэше браузера** (исправляет #84)
  - Тег-носитель `luci.js?v=` задавал `L.env.resource_version` равным только версии темы, поэтому все модули через `L.require()` — включая view-модули других пакетов `luci-app-*` — запрашивались как `?v=<версия темы>`, и после обновления приложения браузер отдавал старую копию
  - Теперь к версии добавляется `pkgs_update_time` (меняется при установке или обновлении любого пакета), как в штатном LuCI; в старом LuCI без этой переменной остаётся версия темы

- **Индекс поиска: «cache persistence failed»** (исправляет #65)
  - uhttpd-mod-ubus не принимает тело запроса больше 64 КБ, поэтому, как только индекс вырастал больше ~30 страниц, сохранение всегда падало с `Parse error`; ответы ubus больше ~1 МБ тоже уходят в таймаут
  - Большой кэш теперь отправляется частями (`saveCacheChunk` + `commitCache`: проверка размера, атомарное переименование, лимит 4 МБ) и всегда читается частями по 256 КБ (`loadCacheChunk`); `saveCache`/`loadCache` оставлены для небольших данных
  - Проверено на OpenWrt 25.12: 40 страниц, 676 записей (79 КБ) — сохраняется и загружается без ошибок

- **Индекс поиска: «[page parse] Cannot read properties of null (reading 'querySelectorAll')»**
  - 16-секундный таймер навигации iframe индексации продолжал работать после загрузки страницы и на медленных страницах (mwan3, acme, графики realtime) удалял фрейм, пока страница ещё отрисовывалась; теперь таймер снимается при загрузке, а страницу ограничивает ожидание рендера

- **Обновление из настроек темы могло показать ошибку, хотя пакет установлен**
  - `postinst` пакета синхронно перезапускал rpcd — внутри того самого вызова `installUpdate`, который запустил менеджер пакетов, и ответ иногда терялся; теперь rpcd и uhttpd перезапускаются в фоне через 3 с
  - Скачанный пакет сверяется с sha256, который GitHub указывает для ассета релиза, и при несовпадении не устанавливается; релиз читается как JSON, URL пакета принимается только из релизов этого репозитория
  - При ошибке запроса к GitHub API теперь упоминается лимит 60 запросов в час вместо «Latest GitHub release not found»
  - Версии сравниваются по всем частям (1.4.4.1 новее 1.4.4), а релиз пакета отбрасывается: на opkg установленная версия приходит как `1.4.3-r1`, последняя часть превращалась в NaN, и на ipk-системах обновление не находилось вообще

- **График температур больше не сплющивается на широких страницах**
  - График рисовался в фиксированном поле 960x320 и растягивался на ширину страницы (`preserveAspectRatio="none"`), поэтому на широкой раскладке линии сплющивались, а текст искажался
  - Теперь он рисуется 1:1 по реальному размеру элемента и перерисовывается при изменении ширины (настройка ширины страницы, изменение размера окна)
  - При 4+ датчиках подписи на концах линий не рисуются (накладывались); значения видны в чипах датчиков и во всплывающей подсказке

## Безопасность

- **Из ACL убраны неиспользуемые права на файлы**
  - В разделе read были выданы `exec` на `/etc/init.d/*` и `/bin/pidof` и `read` на `/proc/cpuinfo`; тема их не использует, но через `file.exec` они позволяли любому пользователю с read-правами темы выполнить, например, `/etc/init.d/firewall stop`

## Уборка

- Удалён `menu-proton2025.core.js`: его не загружает ни один шаблон или модуль, но он попадал в каждый пакет (~43 КБ на флеше)
- Кириллический Inter предзагружается только для кириллических языков интерфейса (на остальных он не использовался, и браузер предупреждал об этом в консоли)
- Больше нет сообщения в консоли на каждой странице о том, что клиентский роутинг выключен (это состояние по умолчанию)
- `CHANGELOG.md`, оба README и `luci.proton-temp` были закоммичены с CRLF, хотя `.gitattributes` требует LF, поэтому после любого checkout они числились изменёнными; нормализованы в LF

## Сборка

- Версия ресурсов (`__pv`) и пакета поднята до 1.4.4.5
- **Заметки к релизу собираются из CHANGELOG**
  - Джоба релиза ставит над инструкцией по установке (тоже на двух языках) раздел `## [<версия>]` из `CHANGELOG_ru.md` (сначала) и `CHANGELOG.md` вместо одной инструкции; если раздела нет, даёт ссылку на CHANGELOG и предупреждение в логе. В форках короткие ссылки `#NN` ведут в основной репозиторий
- **Сборка в CI занимает меньше минуты вместо 15–27 минут**
  - Тема ничего не компилирует, но SDK собирал из исходников всё дерево зависимостей (luci-base, uhttpd, ucode, ubus…); теперь пакеты собираются с `NO_DEPS=1` после сборки только host-инструментов luci-base (`jsmin`, `po2lmo`), а получающиеся ipk/apk побайтно совпадают с полной сборкой
  - Скачивается только фид luci; архив SDK и клон фида кешируются; apk собирается SDK релиза 25.12.5 вместо меняющегося snapshot-SDK
  - Сборка падает, если после минификации в пакете остались файлы `*.js.o`/`*.css.o`
